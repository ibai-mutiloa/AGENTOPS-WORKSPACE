# Development roadmap

## Milestone 0 — foundation

API health, dependency lock, database service and migration, quality tooling, CI, and architecture documents. Verify locally before calling this milestone complete.

## Milestone 1a — secure deterministic vertical slice

Add identity and organization context, synthetic intake, stored product and document fixtures, deterministic extraction, evidence-based draft, exact proposal, approval, simulated send, and audit records. Test two organizations and duplicate execution attempts. No hosted model required.

## Milestone 1b — model-assisted drafting

Add a provider adapter, bounded structured output, model usage accounting, prompt versioning, and deterministic fallback. Keep authorization and compatibility checks outside the model.

## Milestone 2 — persistent agent execution

Add LangGraph checkpoints, interrupt/resume, rejection and edit flows, and process-restart tests.

## Later milestones

Document ingestion and hybrid retrieval; security hardening; evaluation and tracing; Next.js UI; deployment and portfolio material; commercial connectors. Each milestone requires its own measured acceptance evidence.
